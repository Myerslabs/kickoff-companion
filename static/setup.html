Connect a phone or tablet

Any device on the same Wi-Fi opens the app in its browser. Nothing to install: scan the code with the camera, or type the address.

Step 1. Open the app

Open the app

Point the camera at the code and tap the link it shows. Some Android phones cannot use names that end in .local; the number address always works.

Step 2. Add it to the home screen

  • iPhone and iPad (Safari): the Share button, then Add to Home Screen.
  • Android (Chrome): the menu, then Add to Home screen or Install app.
  • A computer: bookmark it, or in Chrome and Edge use Install in the address bar.

After that it opens with one tap, full screen. The app keeps the screen awake during games once you tap anywhere on it.

HTTPS is on: trust the certificate first

This server is set to HTTPS (HTTPS=on in .env), so each device trusts its certificate once before step 1. Two minutes, then it is done for years. Switch HTTPS off to skip this.

Trust it on this device

iPhone and iPad
  1. Tap Download certificate above. Safari asks to allow a configuration profile. Tap Allow, then Close.
  2. Open Settings. Tap Profile Downloaded near the top (or General, then VPN & Device Management). Tap Install, enter your passcode, tap Install again.
  3. Open Settings, General, About. Scroll to the bottom and tap Certificate Trust Settings. Turn on the certificate named above and confirm.
  4. Come back here and open the app.
Android
  1. Tap Download certificate. The file lands in Downloads.
  2. Open Settings and search for CA certificate. It usually sits under Security, Encryption & credentials, Install a certificate. Choose CA certificate, tap Install anyway, and pick the downloaded file.
  3. Android shows a "network may be monitored" notice while a personal certificate is installed. That is expected.
  4. Then open the app from Chrome.
Windows
  1. Click Download certificate, then open the downloaded file and click Install Certificate.
  2. Choose Current User, then Place all certificates in the following store, Browse, and pick Trusted Root Certification Authorities. Finish and accept the security warning.
  3. Or run this in PowerShell after downloading: Import-Certificate -FilePath "$env:USERPROFILE\Downloads\kickoff-companion-ca.crt" -CertStoreLocation Cert:\CurrentUser\Root
  4. Chrome and Edge trust it right away. Firefox keeps its own list; see the Firefox section.
Mac
  1. Click Download certificate and open the file. Keychain Access adds it to the login keychain.
  2. In Keychain Access, double-click the certificate named above, expand Trust, and set When using this certificate to Always Trust. Close the window and enter your password.
Linux, the Steam Deck included
  1. Firefox (the Steam Deck's browser and most others'): follow the Firefox section below. Firefox keeps its own list, so this works without admin rights.
  2. Chrome, Chromium or Edge keep their own list on Linux too. Open chrome://certificate-manager (older versions: Settings, Privacy and security, Security, Manage certificates), go to the certificates you installed yourself, choose the trusted authorities list, click Import, pick the downloaded file, and allow it to identify websites.
  3. For the whole system (command-line tools and other apps; needs admin rights, so not on the Steam Deck's read-only system). Debian or Ubuntu: sudo cp ~/Downloads/kickoff-companion-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates. Fedora or Arch: sudo trust anchor --store ~/Downloads/kickoff-companion-ca.crt.
Firefox on any computer
  1. Click Download certificate in Firefox. A dialog offers to trust the authority. Tick Trust this CA to identify websites and click OK.
  2. On Windows you can instead type about:config in the address bar, search for security.enterprise_roots.enabled, and set it to true so Firefox uses the Windows list.
